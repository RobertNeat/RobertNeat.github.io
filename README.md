# RobertNeat GitHub Pages

Portfolio osobiste hostowane na GitHub Pages.

## Struktura

```
index.html          — strona główna
css/style.css        — style
js/main.js            — logika (menu mobilne, przycisk "do góry", rok w footerze)
assets/images/        — obrazy (avatar.png, project1.png, project2.png, project3.png)
```

## Uzupełnienie treści

- Uzupełnij sekcję "O mnie" w `index.html`.

## Publikacja

W ustawieniach repozytorium na GitHubie: **Settings → Pages → Branch: main → / (root)**.
